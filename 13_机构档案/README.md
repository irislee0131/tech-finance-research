| 类型 | 例子 | 等级 |

## A/B 类归并规则

- **A 类**：银行控股并表的子公司；
- **B 类**：同一金控/集团下、与银行平级的机构；
- 不属于同一并表范围或同一集团的，不并入（如中信建投、兴业证券、招商证券须单列）；
- 具体名单、持股比例以最近一期年报并表范围为准，卡片中标注【待核校】。
