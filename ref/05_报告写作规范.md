# 报告写作规范

版本：v1.2，2026-11-04；补充产业竞争与技术栈的叙事顺序，先以CHIP试点。

本规范适用于面向人类读者的分析报告、专题成稿及 Markdown 文稿。研究笔记、原始资料、数据台账、模型说明和审阅记录按[研究规范](./00_研究规范.md)整理，不受成稿的叙事与排版要求约束。

## 1. 读者与写作目标

读者是具备专业判断能力的人。结合本项目用途，可以使用必要的商业和财务概念；能源、芯片等细分领域术语应在首次影响理解时解释。

用自然、具体、简洁的中文商业写作，让读者顺着正文理解研究问题、证据与结论。信息密度保持中高；材料的完整性由研究底稿承载，正文优先展示影响主要判断的信息。

## 2. Writing Style

- 每节先交代主要发现，再组织“判断 → 证据 → 解释 → 含义”。这是论述顺序，不要求每段都包含四部分，也不使用四个固定标签反复切分正文。证据不足时明确问题或判断边界，避免强造结论。
- 说明读者理解结论所必需的因果关系、计算依据和推断条件。正文不展示内部试错、搜索经过、任务执行日志、审阅往返及问题关闭过程。
- 一段围绕一个主要意思，通常为 2—4 句；根据论述完整性调整，避免为凑句数拆散因果关系。
- 优先写清谁在什么条件下做了什么、造成什么影响。减少抽象名词堆叠、口号式概括和翻译腔。
- 避免反复使用“综合来看”“值得注意的是”“此外”“从上述分析可以看出”等套语；需要转折或承接时，直接写出两段的具体关系。
- 仅在项目确实并列或步骤需要清晰排列时使用列表，保持主体内容为连贯段落。
- 表格用于比较和对应关系；机制、因果和案例经过用段落解释。表前交代比较问题，表后只解释影响判断的差异。
- 保留支撑核心判断的重要数字和证据。正文按分析需要选择精度，底稿保留原始精度；期间、单位、主体与分母等关键口径随数据保留。
- 关键数字按“数值＋对比基准＋含义”呈现，让读者知道它比什么高或低、因此意味着什么。全文选 3—5 个锚点数字，开头与正文表述一致。由底稿数据推算的派生值（如盈亏平衡价、增量比例）须先记入底稿或模型说明，再进入正文。
- 明确区分事实、解释和假设。可使用“披露显示”“据此判断”“在本模型假设下”等自然表达，无须为每句话重复加标签。
- 标题尽量表达本节发现及必要条件，避免所有标题都只列资料类别；标题的确定性不得超过证据。
- 删除重复小结、泛化建议和没有增加信息的收尾。
- 开头先给可检验的全文主判断，不以研究方法、研究路径或“证据不足以……”代替结论；随后列 2—4 条关键发现，每条带一个锚点数字，并用一句话说明对最终用途（银行经营与授信）的含义。引用模型或教学情景的数字时，须在同句标明。
- 限制按影响分级处理：直接决定某项结论是否成立的条件，紧邻该结论保留；一般口径、归因范围、来源层级等限制，集中写入文末“证据边界”；取证状态、核验过程和待补清单留在底稿或 REVIEW。正文段落不以否定式限定作为默认收尾。
- 对跨章节重复的概念集中解释一次，后文直接使用。

正文呈现“结论、证据、必要的机制解释与适用条件”。研究过程记录保留在底稿中，避免为了简洁省略读者理解所需的解释。

## 3. 重点强调（Highlight）

使用 Markdown 加粗标出重点，保持 GitHub、本地 Markdown 和移动端阅读一致。

- 优先强调改变读者判断的发现，例如瓶颈、风险承担、关键差异或结论成立的条件。
- 关键数字与其含义一起强调。例如突出“电价上升后偿债余量接近耗尽”的完整判断，而不孤立加粗一个倍数。
- 对会改变结论的反证或重要限制，可以强调；不得通过加粗把假设、教学结果或局部样本包装成普遍事实。
- 每节通常突出一条主判断，必要时再突出一项关键差异；普通段落通常最多一处加粗。无需为满足数量而强行强调。
- 加粗句应是判断性陈述；研究方法、注意事项和待验证问题不加粗。直接对应最终用途的章节（如银行经营与授信）应有一条加粗主判断。
- 避免整段、整行表格或所有数字加粗。来源编号、文件号、版本、验收状态和过程性提醒不作为正文重点。
- 交付前只扫描标题与加粗句：它们应能连成全文主线，且保留影响判断的关键条件；如仍是互不相关的结论清单，应调整结构。

本节是全项目 Highlight 规则的唯一维护位置，不另建重复的强调规范。

## 4. 从研究材料形成报告

先明确全文主问题和主判断，再选择证据和安排章节。章节按理解与论证需要组织，研究阶段的字段表、案例目录和十二环节检查清单不直接充当报告目录。

产业报告默认先说明“产业分工与代表企业—技术栈差异—竞争点与关键控制环节—中国企业替代进展及约束”，再进入财务、资金需求和银行含义。它是理解顺序，不是强制固定目录：可按主问题合并章节，避免前半篇公司名和术语堆叠，也避免每解释一个技术环节就立即转回授信清单。

代表企业按功能对照；用具体任务解释技术差异，例如为什么内存、通信、算子或认证会影响客户选择。对美国企业的控制力，应写清控制对象、形成机制、适用边界与可削弱它的替代方案，同时明确非美国关键供应节点的归属。财务部分用于解释这些竞争条件如何转化为盈利和资金占用，避免以财务规模代替技术地位。

开头的数字锚点可来自产品范围、系统配置、可比实测或部署证据，不必集中使用财务数字。若关键竞争发现属于定性判断且缺乏可靠可比数字，可使用具体产品、接口或已验证事件作为证据锚点，并说明经营含义；不得为满足数量而添加无来源份额或不具可比性的性能排名。全文仍保留必要的数字锚点，解释其比较基准。

2026-11-04确认的实施顺序为先完成CHIP试点，用户验收后再修改三篇INFRA；更新规范不代表其他报告已经按新要求重写。

正文保留主要发现、代表性数据或案例、必要机制解释及关键限制。完整价格分项、全部模型情景、取证过程、字段缺口和修订记录留在既有底稿或附录，通过链接查阅。案例应解释其支持的判断和适用范围，避免仅因“必须有案例”而并排罗列。

写作时可以重排、合并、压缩及补充已有证据能够支持的解释。新增外部事实、改变模型参数或扩大推断范围，应先回到研究阶段验证；无法验证时保留不确定性。

## 5. 成稿审阅与修订

成稿审阅应具体指出最影响理解的位置，并给出可直接采用的改写或重排方案。重点检查：

1. 读者能否说出全文和各节的主判断，章节是否围绕同一问题递进。
2. 证据是否支持相邻判断，读者是否需要自行补全关键因果关系。
3. 加粗和标题是否突出主线，数据、案例与图表是否各有明确作用。
4. 重要数字、引用、事实／解释／假设的区分及适用条件是否在改写后保留。
5. 产业与竞争：财务分析之前，读者能否说清主要路线、关键依赖、客户切换难点及替代条件；是否把企业宣传或非美国供应节点误写成美国独占能力。
6. 读者测试：只读标题、开头和加粗句，能否复述全文主线、关键数字及其对银行的含义；正文是否仍有大量以否定式限定收尾的段落。

建议新增材料时，同时说明它影响哪个判断、放在何处以及需要替换或重写什么。影响主线的修改应重新组织相关章节，避免在原稿后连续追加说明。

“证据审阅通过”和“成稿审阅通过”分别记录在 REVIEW 文件中。报告正文保留内容版本和资料截止日等阅读必要信息，完整审阅记录通过链接提供。
