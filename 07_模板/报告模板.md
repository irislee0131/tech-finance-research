## 定稿前检查

### 内容

- [ ] 开头有可检验的主判断，不以方法代替结论
- [ ] 2–4 条关键发现，每条有锚点数字和本行含义
- [ ] 全文 3–5 个锚点数字，前后一致
- [ ] 每个关键事实可回到 `relation_id` 或来源
- [ ] 事实、解释、假设分开
- [ ] 无跨行排名、无因果归因
- [ ] 共现未写成协同；立讯标注例外对照
- [ ] 中车集团债未算到上市公司

### 文字

- [ ] 一段一个主要意思，2–4 句
- [ ] 无"综合来看/值得注意的是/此外/从上述分析可以看出"
- [ ] 标题表达发现，确定性不超过证据
- [ ] 加粗句能连成主线，普通段落最多一处
- [ ] 无重复小结、泛化建议、无信息收尾
- [ ] 正文无研究过程、审阅往返、任务日志

### 读者测试

- [ ] 只读标题、开头、加粗句，能复述主线、关键数字及本行含义
- [ ] 正文没有大量以否定式限定收尾的段落
