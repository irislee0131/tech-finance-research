# 研究发现卡模板 v0.1

复制至 `30_编码/研究发现池.md` 或其链接的独立底稿。编号使用 `I-YYYYMMDD-三位序号`，不复用。I 编号标识分析记录，不替代原始证据编号。

## I-YYYYMMDD-001｜候选发现标题

- 研究问题 / 对决策的影响：
- 候选发现（一句可检验陈述）：
- 主体 / 样本 / 期间 / 数据截止日：
- 事实与观察（分开写）：
- 关键证据编号、原文定位及独立性：
- 比较基准（含大行基准）、C1–C4 评级理由（无比较则不适用）：

### 解释与检验

| 候选解释 | 成立时预期看到什么 | 区分性证据及实际结果 | 反证 / 未解决问题 | 保留或排除的理由 |
|---|---|---|---|---|
| 假设 A | | | | |
| 假设 B | | | | |

仅转录事实或记录简单现象时可简写；重要机制解释须比较实质不同的假设。

### 当前结论与边界

- 现象状态：待验证 / 部分支持 / 已验证 / 被否定
- 解释状态：待验证 / 部分支持 / 已验证 / 被否定 / 不适用
- 当前允许的报告表述：
- 尚不支持的推断 / 适用条件：
- 业务或风险含义（区分已支持判断与条件性情景）：
- 什么证据会使判断改变：
- 下一步补证及其预计能改变的判断（无需补证时写明）：

### 反证与报告选择

- 复核者 / 日期 / 方式（自我复核或实际独立复核）：
- 反证检查的主要异议及处理：
- 证据强度 / 增量信息 / 解释能力 / 决策相关性（定性简述）：
- 报告处理：纳入 / 条件性纳入 / 暂缓 / 排除；原因：
- 对应稿件章节（如有）：
- 状态修订记录（日期、旧判断、新判断、依据；保留被否定假设）：
