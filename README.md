# 股份制银行综合经营服务科技龙头企业的模式研究——同业对标与启示

**项目状态**：W1 规范阶段（框架 v2.3 已定稿；研究/写作规范 v0.2 已按参考规范对齐；待进入 W2）
**研究主线**：股份制银行综合经营（母行 + 并表子公司 + 集团兄弟公司）
**核心方法**：结构化同业对标（银行侧正推为主，企业侧反推为辅）
**成果去向**：股份制银行内部研究刊物

---

## 一、课题一句话

以 5 家科技龙头企业为主样本、3 家为例外对照，观察招商银行、中信银行、兴业银行三家股份行如何在资本链、资金链、供应链上组织跨法人服务，回答"股份行靠什么在龙头客户上取得综合收益和不可替代性"。

## 七、约定

- 所有事实性论断标注来源与证据等级（A/B/C/D），规则见数据字典第 8 节。
- 绩效数字必须带"口径、期间、来源"三要素，并标注可比性 C1–C4。
- 绩效默认用"区间 + 方向性"表述，不做跨银行排名与点估计。
- 不做访谈；涉及协同机制的判断需至少两份独立公开来源。
- 例外对照（立讯、美的、海尔）不进入模式归纳，只用于边界讨论。
- 政策文号、日期在引用前逐一核校。
- 版本规则：文档用 vX.Y 递增；旧版保留并加"已被取代"说明。
