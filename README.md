# 股份制银行综合经营服务科技龙头企业的模式研究——同业对标与启示

**项目状态**（2026-11-14）：框架升为 v3.0，研究路径改为银行侧为主体；下一步是工作包 WP1（来源扩展测试）
**研究主线**：股份制银行综合经营（母行 + 并表子公司 + 集团兄弟公司）
**核心方法**：银行侧为主体的结构化同业对标；企业侧作验证窗口；重点是机制解释
**成果去向**：股份制银行内部研究刊物（本行不在三家对标银行之列）

## 一、课题一句话

招商银行、中信银行、兴业银行都宣称以多法人协同服务科技龙头企业。本课题回答：公开证据能看到的实际位置是什么，与银行自述差多少，原因是什么，对本行意味着什么。

## 七、约定

- 银行—企业关系只记入 `20_数据库/relations.csv`；每条记录可回到原文摘录和 URL。
- 共现不等于协同；统计共现时附大行基准。
- 并表子公司（A 类）与集团兄弟公司（B 类）分开表述；招商证券以尾注标明归属。
- 每个数字带口径、期间、来源；披露值照实引用；不做跨银行排名，不做协同收益归因。
- 不做访谈；内部机制只转述银行自述并注明。
- 标【待核校】的事实核实前不进报告正文；清单见框架附录 B。
- 文档用 vX.Y 递增；被取代的版本移入 `ARCHIVE/`。
